# Market Minds

**Learn Money. Understand Markets. Think Bigger.**

A free Baze Learning Lab education project for grades 3–8, centered on Black learners and welcoming to everyone. It introduces money, prices, markets, futures, math, uncertainty, and responsible decision-making.

## Status

**Branding and landing-page foundation only.** The six learning modes are presented as previews; the teaching activities are not yet implemented. No real-money trading, live market prices, accounts, or brokerage connectivity.

## Upcoming learning modes

Learn, Practice, Thinking Lab, Market Lab, Test, and My Progress. Keep Practice separate from Test, offer hints and corrections during practice, revisit missed skills, and track mastery rather than simulated earnings.

## Run locally

Open `index.html` in a browser, or serve the directory using `python -m http.server 8000`. No build tools required.

## GitHub Pages

To publish: repository **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. Published URL is expected to be `https://bazeocrisy.github.io/Market-Minds/` after Pages is enabled and deployment succeeds.

## Learning safeguards

Educational use only. Invented charts and paper/practice scenarios. Futures carry substantial risk, including losses larger than the margin deposit. Never frame this app as instruction to trade real money or promise profit.
